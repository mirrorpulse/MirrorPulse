# Protected root Label target metadata inspection

A pending first-level root Label operation keeps ordinary routing on its current
source Label until complete product settlement. Its original sealed target
members can therefore require metadata inspection before they become ordinarily
routable. `MirrorPulseRootLabelTargetInspection` supplies that narrow internal
inspection scope. It does not execute or complete the Label operation.

The scope requires the shared namespace actor, the current version 3 member
admission, its original Label history and public CfSharp proof, the exact current
root registration, and the original sealed whole subtree. The copied target index
checks the same sync-root anchor, root binding and identity, complete parent/depth
relationships, unique native bindings and case-insensitively unique target names.
Lookups require the exact sealed spelling and object type; there is no prefix,
historical-name, traversal, stream, unregistered-member or alternate-root fallback.

The native metadata-only lease retains every existing drive, ancestor, reparse,
no-recall, object type, handle binding and owner check. It additionally rechecks
the scope, actual target binding and original public identity before returning a
lease and on every inspection. It cannot apply a DACL. The scope expires when
its callback returns, and a changed router registration or lost actor admission
refuses further inspection. Active and Disabled roots retain their exact state;
ordinary routing and Worker dispatch are not enabled by this scope.

The pure path index is not a native access capability. Its managed fixtures use
explicitly synthetic opaque bytes and do not claim public SDK authentication or
native execution. The scope separately decodes the original public SDK encoding;
decoding itself does not replace the SDK's original-store reconciliation.

This is an internal prerequisite for the protected root executor. Its controlled
native execution entry, independent native observations, atomic subtree/Label
settlement, original journal ownership and acknowledgement, startup recovery, and
the complete clean-user fault/concurrency matrix remain separate S06 work. The
generic member executor and public Host/Control/CLI behavior are unchanged by
adding this inspection boundary. Component tests do not close P078 or S06.
