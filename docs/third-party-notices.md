# Third-party notices

MirrorPulse is distributed with notices for its third-party dependencies.
The [dependency notices](dependencies/NOTICE.md) list the package versions,
licenses, and original license and NOTICE files.

The [package inventory](dependencies/inventory.json) and [CycloneDX SBOM](dependencies/bom.cdx.json)
include hashes and cover both runtime dependencies and build inputs. CLI, Host,
and MSIX distributions include these notices under `ThirdParty`. Official
Adapter packages carry their own notices.
