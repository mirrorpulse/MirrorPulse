# Unsealed root Label cancellation during retained initialization

A pending current-inventory initializer can leave different objects at different
verified protection epochs after a Host interruption. Its stable operation ID and
the fingerprint of its immutable original intent must accompany the complete
cancellation inventory. Initial inspection, guarded native reinspection and the
final catalog transaction require the same witness. Missing, substituted or
damaged ownership cannot be replaced with whichever initializer now reserves the
root.

Version 1 cancellation keeps its original JSON shape and applies without an
initializer witness. Version 2 carries the original initializer witness. It closes
only the original unsealed Label; it does not manufacture a namespace move, edit
an initializer reservation or complete initialization. Historical replay retains
the original witness even after that initializer later completes.

The scoped metadata reader validates each object's historical protection and
current committed position. Under this exact pending initializer it retains
structural direct-parent, binding, owner and root checks across mixed roles and
located parent epochs. Ordinary current-role snapshots and all authorization
guards keep requiring coherent roles. Cancellation still inspects every actual
object under the original normal-user boundary, retains the complete guarded
tree, requires actual public NotMoved, reinspects it and atomically verifies the
same current inventory and initializer before recording cancellation.

This component covers verified per-object epochs. Pending original permission
intents still require replay through their original protected operation; this
metadata change does not perform that replay. Retained initializer fences remain
closed after cancellation. Active readiness requires separate current-role
recovery and a fresh complete native audit; Disabled stays closed. Full legacy
recovery, native mixed-epoch and independent Host fault/restart acceptance remain
required beyond the managed catalog tests.
