# Controlled protected root Label execution

The internal root Label executor consumes the original version3 protected-subtree
admission and original public SDK move proof. It verifies the physical sync-root
anchor, every sealed member, complete local child sets, current protection epochs,
source spelling and official projections. It retains the original before-native
start and closes subtree metadata handles before the public SDK move. Recovery
uses the same proof and does not infer movement from Windows path existence.

After successful public reconciliation, a narrowly scoped target metadata reader
permits checks of only the original sealed target members while normal routing
still names the source. Independent native Label evidence, root facts and all
descendant projections precede the existing atomic product transaction. That
transaction transfers names, all positions and the Label together and releases
both durable fences. Current catalog routing is refreshed afterwards, including
when a return was lost after completion. Historical replay never restores an old
Label or authorizes a new native operation.

The new native composite has fourteen independent thirty-second executions:
Active and Disabled roots at success, start-write, after-native,
after-observation, after-projection, final atomic-write and lost-client-return
boundaries. It reopens three catalog/SDK owners, uses the production root policy
for actual movement/recovery, verifies an earlier child move, all private bytes,
strict ordinary deletion refusal, a later case-only Label and immutable original
history. Original preparation and generic/native cases retain their deadlines.

This internal boundary does not activate Host/Control/CLI entry, acknowledge a
journal or upload a source. Its fixture reuses one execution role: a fresh Host
role requires separately proven current-role readmission through immutable owned
recovery lineage. Clean native/installed CI evidence is required. Local builds,
managed catalog tests and discovery alone cannot establish native acceptance.
