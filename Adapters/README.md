# MirrorPulse Adapters

The `official/` directory contains the in-repository provider integrations.
The application installs signed `.mpadapter` releases from the independent
official Adapter repositories.

The SDK, protocol specification, and conformance tools are maintained in the
[Adapter SDK repository](https://github.com/mirrorpulse/adapter-sdk). Start a
new Worker with the [Adapter template](https://github.com/mirrorpulse/adapter-template).
